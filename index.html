Undertow

Sing it. Shape it. Ship it.

A vocal studio that is a folder of static files: pitch detection, tuning, harmonies, a mastering chain and a WAV encoder, all running on your own machine. Nothing is uploaded, nothing needs an account, and there is no build step to trust.

Open the studio Read the setup Runs offline once served.

What is in the box

Twelve tools, all plain JavaScript over Float32Array. Every one is unit tested under Node before it ever reaches the UI.

01

Autotune

Snaps a take to a key in cents, with a strength dial so you can leave some vibrato alone.

02

Harmonies

Stacks up to three intervals from the notes you actually sang, each with its own level and spread.

03

Voice characters

Resample, tilt the treble, add soft drive and breath to push a voice somewhere else entirely.

04

Stem split

A frame-median harmonic and percussive split. Crude by design, and it recombines sample-exactly.

05

Beat generator

Synthesized kick, snare and hats rendered from a genre and a bar count. Same input, same beat.

06

Melody generator

A seeded walk through the scale, one or two steps at a time, so an idea is reproducible.

07

Chord generator

Triads stacked from scale degrees, one per bar, to hum against while the take is still rough.

08

Automix

Suggests EQ and compression from the genre, and level trims that pull a stack of tracks together.

09

Mastering chain

EQ into a compressor into loudness targeting into a limiter, then meters the true post-chain peak.

10

Presets

Versioned JSON patches with range validation, import and export. A broken file is rejected, not half-applied.

11

WAV export

16-bit stereo PCM at 44.1 or 48 kHz, assembled byte by byte in the page and handed to the download shelf.

12

Project save

The take, the notes and the patch settings in one JSON file you can reopen later or move to another machine.

How it works

Three steps, no wizard, no upload progress bar.

Sing it

Hit record and sing a phrase. Undertow tracks the pitch per frame and turns the take into editable notes you can drag, retune or delete.

Shape it

Snap to a key, stack harmonies, pick a character, drop a beat under it, then let the master chain find the ceiling.

Ship it

Export a WAV. Save the project if you want it back. The file is yours and the audio never left the machine.

Why local-only

  • No accountThere is no sign-up, no session, no dashboard holding your stems.
  • No uploadCapture, tuning and rendering all happen in the tab, on the CPU you already own.
  • No dependenciesThe whole studio is static files. Serve the folder and it works offline.
